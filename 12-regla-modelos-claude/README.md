# Cuándo usar Haiku, Sonnet, Opus o Fable

Usar siempre el modelo más caro es tirar plata. La idea es elegir el modelo según la tarea, no por costumbre.

## La guía

Está en [`prompt.txt`](prompt.txt) — regla rápida de cuándo usar cada modelo, y cómo cambiarlo con `/model` o `claude --model`.

## Resumen

- **Haiku** → tareas mecánicas: buscar, formatear, cambios chicos, resúmenes.
- **Sonnet** → tu default: el 70-80% del trabajo día a día.
- **Opus** → arquitectura, bugs difíciles, decisiones con trade-offs fuertes.
- **Fable** → solo lo extremo. Si no podés explicar por qué lo necesitás, no lo necesitás.
