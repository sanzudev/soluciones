## Qué es

Un repositorio que analizó y recopiló las charlas de diseño de Apple y las metió en una skill de Claude Code. Trae 7 skills enfocadas en diseño (animaciones, jerarquía visual, interfaces limpias) — una de ellas, `apple-design`, son los principios de Apple traducidos para la web.
