# Hacé que Claude te frene cuando la idea es mala

Claude está entrenado para ser útil y amable, así que a veces te banca ideas malas o inventa cosas cuando no está seguro. Este prompt le pone reglas claras: si no sabe algo, que lo diga; si tu idea es mala, que te frene antes de que te pongas a codear.
