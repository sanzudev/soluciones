# Hacé que Claude te frene cuando la idea es mala

**Video:** "Si Claude siempre te da la razón… estás usando mal a Claude." (16 de agosto) · Palabra clave: `SINCERO`

## El prompt

Está en [`prompt.txt`](prompt.txt) — reglas de honestidad para que Claude objete tus ideas malas antes de ejecutarlas, en vez de darte la razón por amabilidad.

## Cómo lo uso en el bot

Cuando alguien comenta `SINCERO`, se le manda este prompt por privado (después de seguir la cuenta).
