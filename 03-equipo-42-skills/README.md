# Un equipo entero de 42 skills dentro de Claude Code

42 skills organizadas en 7 áreas — desarrollo, diseño, marketing, contenido, finanzas, operaciones y legal. No están inventadas: salen de colecciones públicas ya existentes, revisadas una por una y mapeadas por departamento (ej: diseño trae los principios de Apple, finanzas avisa antes de quemar presupuesto, legal escanea la configuración buscando agujeros).
