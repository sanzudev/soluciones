# Un equipo entero de 42 skills dentro de Claude Code

**Video:** "Armé el equipo entero adentro de Claude Code: 42 skills reales, 7 áreas." (28 de julio) · Palabra clave: `EQUIPO`

## Qué es

42 skills organizadas en 7 áreas — desarrollo, diseño, marketing, contenido, finanzas, operaciones y legal. No las inventaste vos: las sacaste de colecciones públicas ya existentes, las revisaste una por una y armaste el mapa por departamento (ej: diseño trae los principios de Apple, finanzas avisa antes de quemar presupuesto, legal escanea la config buscando agujeros).

## ⚠️ Pendiente

No tengo el mapa completo (las 42 skills, de qué colecciones públicas salió cada una, ni los comandos de instalación) — esto lo armaste vos a mano revisando colecciones, así que no lo puedo reconstruir por mi cuenta sin arriesgarme a inventar cosas que no coincidan.

**Pasame el mapa** (documento, notas, o lo que hayas usado para armar esto) y te dejo la carpeta completa con el repo y los comandos de instalación de cada skill.
