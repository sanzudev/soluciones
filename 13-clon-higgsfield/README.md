# Clon open source de Higgsfield

Higgsfield cobra suscripción para generar imágenes, video y lipsync con IA. Este repo es una alternativa open source: conectás tu propia API key de los modelos que quieras usar (Flux, SDXL, Midjourney, Ideogram, Kling, Sora, Veo, y más) y generás sin pagar la suscripción. Solo pagás el uso real de cada API que conectes.

Es de **Anil Matcha**, con decenas de miles de estrellas en GitHub.
