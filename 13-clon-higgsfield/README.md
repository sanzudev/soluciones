# Clon open source de Higgsfield

**Video:** "Acaban de clonar a Higgsfield." (23 de agosto) · Palabra clave: `VIDEO`

## Qué es

Higgsfield cobra suscripción para generar imágenes, video y lipsync con IA. Este repo es una alternativa open source: conectás tu propia API key de los modelos (Flux, SDXL, Midjourney, Ideogram, Kling, Sora, Veo, etc.) y generás sin pagar la suscripción de Higgsfield. Solo pagás el uso real de cada API que conectes.

Es de **Anil Matcha**, tiene decenas de miles de estrellas en GitHub.

## El repo

👉 https://github.com/Anil-matcha/Open-Higgsfield-AI

Instrucciones de instalación y self-hosting están en el propio README de ese repo.

## Cómo lo uso en el bot

Cuando alguien comenta `VIDEO` en el video, se le manda por privado el link de arriba (después de seguir la cuenta).
