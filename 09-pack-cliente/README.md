# El pack profesional para cuando te dicen que sí

Cuando un cliente potencial dice que sí, la mayoría improvisa por WhatsApp. Este prompt arma el proceso completo de una sola vez: confirmación, contrato, cobro, onboarding, carpetas, bienvenida y kickoff.

## El prompt

Está en [`prompt.txt`](prompt.txt) — antes de generar nada, te pregunta por tu negocio, tu forma de cobrar y tu tono, para que todo salga adaptado a vos.

## Qué te entrega

1. Mensaje de confirmación de contratación
2. Contrato / acuerdo de servicio simple y profesional
3. Instrucciones de facturación / pago inicial
4. Formulario de onboarding
5. Estructura de carpetas del cliente
6. Mensaje de bienvenida
7. Guion corto para la reunión de kickoff
8. El proceso presentado en etapas (Discovery → Strategy → Development → Testing → Deployment → Optimization)
9. Checklist interno desde el "sí" hasta el kickoff
